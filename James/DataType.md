# Python Data Type Exercises

## Basic Data Types (1--7)

### 1. Identify the Data Type

What is the data type of each value?

``` python
42
3.14
"Python"
True
```

### 2. Create Variables

Create four variables: - An integer called `age` - A float called
`height` - A string called `name` - A boolean called `is_student`

### 3. Change a Variable

Create a variable:

``` python
score = 50
```

Update it so the value becomes `75`.

### 4. Type Conversion

Convert the following values: - Integer → Float - Float → Integer -
Integer → String - String `"25"` → Integer

### 5. Check the Data Type

Use the `type()` function to print the data type of:

``` python
100
"Hello"
False
6.28
```

### 6. Calculate with Different Types

What is the result and data type of:

``` python
5 + 2
5 / 2
5 // 2
5 % 2
5 ** 2
```

### 7. Boolean Expressions

What do these expressions return?

``` python
5 > 3
10 == 5
7 <= 7
4 != 8
```

# Strings (8--13)

### 8. String Length

### 9. Access Characters

``` python

```

### 10. Join Strings

Create two variables:

``` python
first = "Hello"
second = "World"
```

Join them into:

``` text

```

### 11. Convert Case

Given:

``` python
text = "PyThOn"
```

Print: - All uppercase - All lowercase

### 12. Count Characters

Given:

``` python
sentence = "banana"
```

Count how many times `"a"` appears.

### 13. Replace Text

Replace `"cat"` with `"dog"` in:

``` python
"The cat is sleeping."
```
